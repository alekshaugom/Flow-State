A snapshot of the new look. We kept Flow State's real data — USGS gauges, flow status, corridors, guided trips — and re-skinned it in an Apple Weather × AllTrails language: immersive sky canvases, frosted instrument modules, big airy numbers, calm color. Scroll to explore the system.
Riverflow · today
Good window Open gauge
What changed. This is a ground-up visual + experience shift. Out: flat light cards, the single river-blue accent, tiny mono eyebrows everywhere, decorative status dots. In: condition-reactive sky gradients, frosted instrument modules, Manrope with Inter numerals, big light-weight readouts, a calm 4-step status ramp, and an immersive, mobile-first feel that broadens from rivers into snowpack, weather and guided trips. The status colors still carry data meaning and numbers stay tabular — the bones the old system got right.
Foundations

Color

Flow blue is the primary brand (river / glacier); alpine green is secondary (trails / land / "go"). A cool, faintly-blue ink scale carries text and light surfaces. Condition status is a strict 4-step ramp reserved for data meaning. Colors are authored in OKLCH.

Type

Manrope carries headings, body and UI. Numerals render in Inter (mapped onto digits via unicode-range) — notice the numbers below are Inter while letters stay Manrope. Spline Sans Mono is the instrument face for codes, coordinates and axis labels. Big condition numbers are light (300) and large for an airy, premium feel.

Components

Blend map

A frameless "blend" map — no boxed frame, the river network drawn directly: flow-blue main stem with a glowing selected reach, tributaries, access points (alpine = put-in, flow = take-out), live FlowGauge markers with CFS chips, and soft snowpack blotches. Production rides on MapLibre + OSM + USGS NHD hydrography.
